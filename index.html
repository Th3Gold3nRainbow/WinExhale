Nine modules, one console

Every tool WinExhale ships with, built around the same principle: show exactly what's about to change before it changes.

01

Windows Debloater

Removes preinstalled OEM apps, Cortana, Xbox overlays, and promotional software through official Appx removal APIs.

02

Privacy & Telemetry Hardening

Disables DiagTrack, the Advertising ID, Windows Error Reporting, and Cortana's cloud search tracking.

03

Performance & Game Mode

Switches to a low-latency power plan and streamlines SysMain and indexing — revert to default anytime.

04

Windows Annoyances

Kills the Sticky Keys popup, Start menu web search, lock-screen ads, and taskbar news widgets.

05
detachable

DNS Optimizer

Benchmarks Cloudflare, Google, Quad9, and AdGuard live, then applies the fastest resolver automatically. Pop it out into a small floating widget to keep latency in view while you work.

06

App Installer

Deploys common software through winget across five categories, with live terminal output as it runs.

07

Safe Startup Manager

Scans registry and folder startup entries and toggles them non-destructively — full rollback, always.

08
detachable

Deep Junk & Cache Cleaner

Clears temp files, DNS cache, and GPU shader cache, with a live counter of space freed. Also available as a floating widget you can leave open on the desktop.

09

Bilingual Interface

Full English/French localization with instant switching, in the same dark cyan theme throughout.

New — detach any module into a floating widget

The Junk Cleaner and DNS Optimizer can now pop out of the main console into small, always-on-top panels you can leave running on the desktop. Drag them anywhere, watch cache get reclaimed or DNS latency update live, and close them back into the main window whenever you're done — the rest of WinExhale keeps running underneath.

Nothing changes without a safety net

WinExhale creates a System Restore Point before batch operations and keeps non-destructive backups of every startup item it touches. Toggling something off keeps the original entry intact — turning it back on restores it exactly as it was. Review any tweak before you apply it; nothing runs automatically.

Build from source

Requires Windows 10 or 11, Python 3.10+, and Git.

Clone the repository

git clone https://github.com/Th3Gold3nRainbow/WinExhale.git cd WinExhale

Install dependencies

python -m pip install --upgrade pip pip install -r requirements.txt

Generate icons and logo assets

python generate_assets.py

Run it locally

python main.py

Compile a standalone executable

pyinstaller WinExhale.spec --noconfirm --clean

Optional — build the Inno Setup installer

ISCC.exe installer.iss

Get WinExhale

Grab the installer for desktop shortcuts and an uninstaller, or run the portable .exe from anywhere — no install needed.
